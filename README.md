# Sako Design Studio

Bespoke Haute-Luxury Interior Design Studio in Aundh, Pune.

## Tech Stack
- **Framework**: React (v19)
- **Runtime & Build Tool**: Vite, TypeScript
- **Styling**: Tailwind CSS (v4)
- **Animations**: Motion
- **Icons**: Lucide React
